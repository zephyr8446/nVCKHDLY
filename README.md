# 项目简介
基于深度学习（BlazePose模型）的人体姿态识别项目旨在提供高效、实时的健身动作识别与计数功能。

## 核心功能
1. **健身动作实时计数**
2. **视频动作计数分析**
3. **关键点检测**
   - 支持图片输入
   - 支持视频输入
   - 支持实时摄像头输入
4. **姿态分析和可视化**

## 适用场景
- 健身教练辅助教学
- 个人健身训练记录
- 运动数据统计与分析

## 技术特点
- **高精度关键点检测**：利用MediaPipe技术实现人体关键点检测，提取33个关键点坐标。
- **实时处理能力**：支持摄像头实时输入和视频文件输入，实现快速姿态识别。
- **动作识别与计数**：基于预训练模型进行姿态分类，跟踪动作状态变化，统计有效重复次数。
